# 可选 QA 简报

只保留有助于审查当前任务的字段。简报可以直接作为消息，无需落文件。

```markdown
## 目标与范围
[原始请求、约定行为、相关既有契约与授权边界。]

## 审查对象
[工作区、版本、未提交改动、相关入口及文件。]

## 主要风险
[实现可能无法满足目标的具体方式。]

## 已有证据
[执行过的检查和结果；区分通过、失败、受阻、未测试。]

## UI 证据（如适用）
[截图路径，以及对应状态、操作、页面、视口和浏览器环境。]
[动态行为的前后截图，以及必要的补充录屏或日志。]
[分别标明 Agent 验证与用户人工审核状态；缺少截图属于证据缺口。]

## 审查要求
只读审查，追踪真实执行路径并尝试反例。
分别报告有证据及修正方向的新增发现、独立复现的已有检查、未知事项。
不要根据实现者总结推断正确，也不要给出不限定范围的 PASS。
```
