# 持久化交接模板

仅用于用户明确要求项目内留档、跨工具交接、历史无法恢复或长期中断。替换过时内容，不追加流水账。

```markdown
# 交接说明

## 目标
[具体结果和验收标准。]

## 状态
- 已完成：
- 进行中：
- 阻碍：

## 相关文件
- `[路径]`：[重要性]

## 工作副本状态
- 项目或 worktree：`[已核验路径]`
- 分支、HEAD 与同步状态：[已核验状态]
- 未提交修改或用户状态：[必须保留的内容]

## 已做修改
- [具体改动]

## 验证
- `[命令]`：[结果摘要]

## 决策
- [决策]：[原因]
- [未采用方案]：[放弃原因]

## 下次开始步骤
1. 阅读 `[路径]`。
2. 执行 `[安全核验命令]`。
3. 继续 [具体实现或审查步骤]。

## 重新核验
- [远端状态、检查、进程、权限等易变事实]

## 边界
- 未获用户要求，不修改 [文件或范围]。
- 保留 [用户偏好或不变量]。
- 本说明不授予 [commit、push、PR、部署、发布或其他外部写入] 权限。

## 未决问题
- [仍需确认的问题或假设]
```
