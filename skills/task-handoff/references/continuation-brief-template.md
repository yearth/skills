# 启动说明模板

用于新任务或新会话，省略不适用的章节。

```markdown
# 续作说明

## 目标
[具体结果和验收标准。]

## 范围与当前状态
- 项目或 worktree：`[已核验路径]`
- 分支、HEAD 与同步状态：[已核验状态]
- 未提交修改或用户状态：[必须保留的内容]

## 已完成工作与证据
- [已完成动作]：[关键结果或验证证据]

## 决策与约束
- [决策或范围边界]
- [授权边界]

## 开始步骤
1. 阅读 `[最少必要文件]`。
2. 执行 `[第一条安全核验命令]`。
3. 继续 [下一项具体行动]。

## 重新核验
- [远端状态、检查、进程、权限等易变事实]

## 支撑材料
- `[路径]`：[需要它的原因]
```
